# 洗稿 · note-rewrite

保留文章核心表达和关键锚点含义，重新组织文案；图片完全临摹原图，在关键锚点处修改替换主体和背景。支持纯文字改写与同主题多篇图文制作。

例如原文的核心是“搭子根据天气教你穿搭”，新稿重写建议，图片完整临摹原构图、卡片排版和信息层级，在原有位置换整套衣物、鞋包配件及对应背景，核心仍是“搭子根据天气教你穿搭”。锚点保留功能含义，具体主体可以替换；人物、地点和作息不要求每篇重设。

## 工作流程

1. 读完整原文及全部配图，提炼核心表达和关键锚点。
2. 分别列清文字改写范围、图片临摹布局、锚点对应的主体背景替换区域和用户指定不动的部分。
3. 为每篇设计新的表达方案，不强制换主题或场景。
4. 同步重写文案、指令和对应成果。
5. 用原图逐页作为 AI 编辑参考，完整临摹构图、排版与信息层级，在关键锚点处替换主体和背景，保证品牌、文字和数据准确。
6. 检查核心完整、替换范围、前后一致性及篇间差异。
7. 按范围交付文字或图片、文案、预览和 ZIP。

完整规则见 [SKILL.md](skills/note-rewrite/SKILL.md)。

## 依赖与交付

纯文字改写没有额外脚本依赖。图文制作需要所在环境提供图像生成/编辑能力；精确贴图和排字遵循当前工具规则及有效授权。

本 skill 可独立运行。百度搭子内容可结合当前环境已安装的 `$dazi-note-studio` 和现有品牌/UI 素材，也可使用用户提供的准确资料；仓库不包含私有素材库，不依赖仓库外的相对链接。

不固定文章字数或人物场景；图片默认沿用参考的比例、页数与顺序，用户具体要求优先。版本差异来自文字表达及图片主体、背景替换，不要求另外重设计构图。真实数据和实测结果保持准确，改写后仍需保留原文关键功能、条件和结论。

仓库包含 `skills/note-rewrite/SKILL.md` 和界面元数据 `agents/openai.yaml`，不包含参考原稿、生成图片或客户素材。
