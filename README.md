# 洗稿 · note-rewrite

**不同版本表现不同，核心内容完全相同。** 保留核心表达与关键锚点，改写文案；图片以原图为临摹参考，主体、背景、配色、构图和排版都可修改。支持纯文字改写与同主题多篇图文制作。

例如原文的核心是“搭子根据天气教你穿搭”，新稿可以重写建议，换整套衣物、鞋包配件、背景与卡片构图排版，核心仍是“搭子根据天气教你穿搭”。原文介绍的关键功能、条件、过程与成果完整保留，不能只留下一个泛化主题。人物、地点和作息不要求每篇重设。

## 最新约束：真实界面与官号投放（2026-10-15，2026-10-22同步）

以下规则适用于百度搭子图文；官号口吻规则仅针对官号投放用途，其他项目不自动套用。

- 封面与发布标题不同时出现“百度搭子”，全部交付图文禁用英文品牌名及其变体。
- 使用实际操作搭子的截图和对应成果，可保真裁切、放大、标注、拼版；不生成使用场景，不重画或篡改界面。实际由搭子生成的成果需有对应真实操作来源。
- 官号采用官方产品演示与使用指引表达，不以KOS或素人视角安利；使用已核实的中文官方Logo，原样等比放置。
- 每篇呈现同一任务的真实输入/对话到成品，正文附可复制提示词；入口、按钮及操作词逐项核对真实界面。
- 沿原稿的视觉风格实质更换内容、主体、案例、背景或布局；同一主题形成明显新画面，不能整页照搬，也不能一律改成说明书模板。
- 原稿同任务真实素材可复用；缺图或更换案例后不匹配时，按任务授权补采。逐页目检、OCR辅助检查、预览与ZIP版本核对后交付。

详细规则见 [SKILL.md](skills/note-rewrite/SKILL.md#百度搭子项目新增约束-2026-10-15)。

## 工作流程

1. 读完整原文及全部配图，提炼核心表达和关键锚点。
2. 列清核心内容、可改的文字与图片表现形式、用户明确指定不动的部分。
3. 为每篇设计新的表达方案，不强制换主题或场景。
4. 同步重写文案、指令和对应成果。
5. 百度搭子图文使用同任务真实界面与成果保真拼版；其他主题按适用规则编辑。沿原稿风格实质修改表现，完整表达相同的功能与成果。
6. 检查各篇表现是否不同，核心内容是否完全相同，以及篇内前后一致性。
7. 按范围交付文字或图片、文案、预览和 ZIP。

完整规则见 [SKILL.md](skills/note-rewrite/SKILL.md)。

## 依赖与交付

纯文字改写没有额外脚本依赖。图文制作需要所在环境提供图像生成/编辑能力；精确贴图和排字遵循当前工具规则及有效授权。

本 skill 可独立运行。百度搭子内容可结合当前环境已安装的 `$dazi-note-studio` 和现有品牌/UI 素材，也可使用用户提供的准确资料；仓库不包含私有素材库，不依赖仓库外的相对链接。

不固定文章字数或人物场景；图片尺寸和页数按用户要求，分镜与顺序可重新组织。文案、主体、背景、配色、构图和排版都可形成版本差异。真实数据和实测结果保持准确，各篇仍需完整表达相同的核心功能、条件、过程、成果与收益。

仓库包含 `skills/note-rewrite/SKILL.md` 和界面元数据 `agents/openai.yaml`，不包含参考原稿、生成图片或客户素材。
