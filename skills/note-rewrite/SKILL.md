# 洗稿

**文章核心表达和关键锚点的含义保持一致，文字表达重新组织；图片完全临摹原图，在关键锚点处修改替换主体、背景。**

先理解原文希望读者记住什么，再用新的叙述角度、句式、结构和例子把同一个意思讲出来。文字改写与图片处理分别执行：图片以原图为完整临摹依据，沿用构图、排版、信息层级和视觉关系，围绕关键锚点替换对应的主体与背景。保留核心内容的完整度；不将逐句换同义词作为完成标准。

例如，原文的核心是“百度搭子根据天气教你穿搭”。新稿重写穿搭建议，图片完整临摹原图，在原有位置换整套衣物、鞋包配件及对应背景，仍讲“搭子根据天气教你穿搭”。关键锚点保留的是功能含义，锚点对应的具体表现对象可以替换；其他主题按其自身对象处理，不把每篇换衣服写成通用要求。

## 使用范围与资料

用户要求“洗稿、照这篇改写、同样内容换表达、参考做几篇、除关键锚点外都换一次”时使用。用户只要求总结流程或修改 skill 时，交付相应文档或 skill；要求成品时完成指定的文字或图文。

优先使用用户指定的参考。读原文和全部配图，拟用界面看原尺寸；缺少原文或图片时先查现有项目素材，再补充必要材料。不要只读摘要就声称看完原稿，也不为一次指定参考改写额外搜集大量无关样本。

本 skill 可独立用于文章和图文改写。制作百度搭子笔记时，若当前环境已安装 `$dazi-note-studio`，读取其入口并使用适用的品牌、界面素材、产品事实和审核规范；未安装时使用用户提供的准确资料，不依赖仓库外的相对路径，也不编造产品界面。本 skill 负责确定改写范围与保证核心表达不变；其他主题按各自素材和规范执行。

## 制作流程

### 1. 拆清原文核心

用一句话写清原文的核心表达，再列出关键锚点：主旨、产品/品牌、主要功能、必要条件、关键步骤、成果类型和读者收益。区分锚点的功能含义与其图片中的具体主体：功能含义保留，具体主体与背景按该锚点修改替换。文字措辞和示意例子可重写，图片构图与排版按原图临摹。

如果原文同时介绍定时任务、天气检索和可视化穿搭报告，新稿仍要完整传达这些内容，不能只留下“搭子会穿搭”一句泛化卖点。

### 2. 列保留与替换清单

制作前分别记录文字与图片的保留、替换范围：

| 层次 | 处理方式 |
| --- | --- |
| 核心表达与关键锚点 | 含义保留，可换说法和出现顺序；不改变主推功能、关键条件或结论 |
| 文字表达与具体例子 | 按改写范围重写标题、开头、叙述角度、段落组织、图内文案和例子；图内文字仍放在原图对应位置 |
| 图片临摹与替换 | 完全临摹原图的构图、排版、信息层级、主体位置与比例；标出关键锚点对应区域，在这些位置修改替换主体与背景 |
| 用户指定保留的内容及真实事实 | 按指定范围保留；真实数据、实测结果、引用结论不为制造差异而改造 |

图片默认按“完整临摹＋关键锚点处主体、背景替换”执行，不能将文字改写范围扩大成整张图自由重设计。用户锁定的截图、数据或主体按指定范围保护；后续明确调整时以最新要求更新清单。只修改skill时不重新生成图片；用户要求返修成品时再同步修图。

### 3. 设计每篇新的表达方案

为每篇确定如何重新讲述同一个核心：从什么角度开场、文字按什么顺序展开、用哪些具体例子；图片逐页对应原参考，列出关键锚点处要替换的主体和背景。

人物、痛点、地点、作息可在有助于表达时调整，**不要求每篇重新设定这些条件，不强制转成另一个场景或换掉文章主题。** 同批版本通过文案组织、具体对象和背景替换形成差异；图片保持对原图的完整临摹，不强制每篇另做构图。

替换对象按任务处理。例如穿搭在原图位置换整套衣物及对应鞋包配件，旅行在原版式中换景点或路线示例，资料整理在原成果版式中换示意材料；各自配合对应背景替换。用户锁定原主体时保留该主体，只调整获准替换的部分。

记录该篇实际采用的条件、对象和参数，供输入、对话、结果、图片和正文共同使用。无需改变的参数不为了差异强行替换。

### 4. 重写文案、指令和对应成果

围绕保留的核心重新组织标题、正文、图内文字和相关话题，从新的表达方案写起。重新安排论述顺序和具体动作，避免沿原文逐句替换。删去空泛夸赞和制作口吻，保持自然的使用者表达。

涉及工具操作时，写出可读、可复制的用户指令，再准备对应的可见成果。改过的条件贯穿任务名、输入、对话、文件名、输出卡、预览及正文；只需修改与该条件有关的内容。

图文任务默认逐页对应原参考，沿用页序与各页的信息职责；替换后的文字和成果放回原有布局。用户明确要求增减页或调整结构时再按其要求处理。保留原文的重要功能、过程与收益，不能为了缩短文案漏掉关键锚点。

### 5. 完整临摹原图，在关键锚点处替换主体与背景

每张图以对应原图为图像编辑参考，用AI完成临摹与局部替换。保留原图的构图、排版、信息层级、元素位置与比例、视觉风格及阅读顺序；在关键锚点对应位置修改替换主体、背景及必要的关联内容。背景替换可带来相应色彩变化，不额外要求整页换配色或重新设计版式。

逐图提示词明确写出：完整临摹哪张原图、哪些布局保持、哪个关键锚点区域换成什么主体与背景、哪些文字与参数要同步。替换要落在原图对应位置，避免生成工具把整张图改成另一套设计。临摹保持视觉形式，核心功能和成果含义保持准确。

原搭子界面可以复用。产品品牌、控件和布局有真实素材依据；其中需要改写的场景文字和结果按本篇条件同步调整。默认无需每篇重新登录运行任务，用户要求实测时再实际操作。

长中文、品牌、数字和密集图表逐字核对；必要时保真贴图或准确排字。图像编辑遵循当前工具规则，需要程序合成时使用已有适用授权；不能自行以程序重绘替代默认图像编辑工具。

同篇主体、对象和参数一致，各版本图片均与对应原图的构图、版式吻合，差异体现在获准替换的主体与背景。保留原素材；记录实际生图提示词、素材来源、锚点替换区域及局部修正。复用同一素材制作多个页面时，不把这些页面记为多次独立生图调用。

### 6. 检查核心、改写范围和前后一致性

对照原稿与最终成品检查：

- 核心表达是否仍相同，关键锚点是否完整，重要条件和结论是否被误改。
- 应替换的文字和例子是否已重写；改过的城市、姓名、日期、服装、文件等是否还有旧内容残留。
- 输入、指令、对话、成果、图表和正文是否属于同一篇任务；数值、对象和建议是否相互对应。
- 文案是否已换表达；图片是否完整临摹原图，构图、排版和信息层级是否吻合，关键锚点处的主体与背景是否按清单完成替换。
- 图片是否有乱码、遮挡、拉伸、糊小字或品牌错误；提示词与成果是否清楚可读。

逐图看原尺寸，再看手机阅读尺寸和整组预览。文字检索辅助检查，不替代看图。发现问题修最终文字或图片，不能只改提示词或补解释。

内部区分原始截图、AI 场景、示意成果和本次实测；合成内容不记录为原始截图或实际运行结果。示意数据可随示意场景调整，真实引用内容保持准确。

### 7. 交付和记录

按用户范围交付。纯文字任务给完整新稿；图文任务默认交付有序图片、标题/正文/话题、可复制用户指令、整组预览和 ZIP。图片沿用原参考的比例、页数与顺序，用户另行指定时按其要求。

保存原参考、保留/替换清单、各篇表达方案、准确内容与参数、实际生图提示词、来源和修正记录。检查文件数量、预览引用和 ZIP 完整性。原稿和旧版保留；发布或外部同步按当轮授权执行。

## 主题迁移举例

| 原文核心表达 | 可替换的表达形式 | 保留的核心 |
| --- | --- | --- |
| 搭子根据天气教你穿搭 | 重写开场和建议；图片完整临摹原构图与卡片排版，换整套衣物、鞋包配件及对应背景；示意条件变动时同步改建议 | 天气指导穿衣；原文关键功能和报告内容仍完整 |
| 搭子帮你规划旅行 | 重写叙述；图片临摹原地图、行程排版，在对应位置替换景点、路线示例及背景 | 搭子规划旅行，必要条件和成果内容不遗漏 |
| 搭子帮你整理资料 | 重写说明；图片临摹原报告与成果布局，在对应位置替换示意文件、主体及背景 | 搭子处理资料并给出可用的整理结果 |
