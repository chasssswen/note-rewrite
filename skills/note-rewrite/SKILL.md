# 洗稿

**文章核心表达和关键锚点保持一致，文章的表达形式重新组织。**

先理解原文希望读者记住什么，再用新的叙述角度、句式、结构、例子和画面把同一个意思讲出来。保留核心内容的完整度；不将逐句换同义词作为完成标准。

例如，原文的核心是“百度搭子根据天气教你穿搭”。新稿可以换一套衣服、重写穿搭建议、更换卡片排版与配色，但仍讲“搭子根据天气教你穿搭”。穿搭是具体表现对象，其他主题按其自身对象处理，不把每篇换衣服写成通用要求。

## 使用范围与资料

用户要求“洗稿、照这篇改写、同样内容换表达、参考做几篇、除关键锚点外都换一次”时使用。用户只要求总结流程或修改 skill 时，交付相应文档或 skill；要求成品时完成指定的文字或图文。

优先使用用户指定的参考。读原文和全部配图，拟用界面看原尺寸；缺少原文或图片时先查现有项目素材，再补充必要材料。不要只读摘要就声称看完原稿，也不为一次指定参考改写额外搜集大量无关样本。

本 skill 可独立用于文章和图文改写。制作百度搭子笔记时，若当前环境已安装 `$dazi-note-studio`，读取其入口并使用适用的品牌、界面素材、产品事实和审核规范；未安装时使用用户提供的准确资料，不依赖仓库外的相对路径，也不编造产品界面。本 skill 负责确定改写范围与保证核心表达不变；其他主题按各自素材和规范执行。

## 制作流程

### 1. 拆清原文核心

用一句话写清原文的核心表达，再列出关键锚点：主旨、主体/品牌、主要功能、必要条件、关键步骤、成果类型和读者收益。只保留对这篇文章成立不可缺少的锚点，不把所有具体措辞、示意例子和排版都锁死。

如果原文同时介绍定时任务、天气检索和可视化穿搭报告，新稿仍要完整传达这些内容，不能只留下“搭子会穿搭”一句泛化卖点。

### 2. 列保留与替换清单

制作前记录三个层次：

| 层次 | 处理方式 |
| --- | --- |
| 核心表达与关键锚点 | 含义保留，可换说法和出现顺序；不改变主推功能、关键条件或结论 |
| 表达形式与具体例子 | 按改写范围重写标题、开头、叙述角度、段落组织、图内文案和例子；图片调整配色、排版、主体呈现 |
| 用户指定保留的内容及真实事实 | 按指定范围保留；真实数据、实测结果、引用结论不为制造差异而改造 |

用户要求“图片内容原样保留”时，按范围保护内容，只改允许的视觉部分；用户进一步明确“只保留关键锚点”时，以最新要求更新替换清单，并同步返修已制作页面。已有明确范围就继续执行。

### 3. 设计每篇新的表达方案

为每篇确定如何重新讲述同一个核心：从什么角度开场、信息按什么顺序展开、用哪些具体例子、怎样展示成果、图片如何引导阅读。

人物、痛点、地点、作息可在有助于表达时调整，**不要求每篇重新设定这些条件，不强制转成另一个场景或换掉文章主题。** 同批版本通过文案组织、例子或对象、构图等形成可见差异；不只换标题和颜色。

替换对象按任务处理。例如穿搭换衣物组合及对应鞋包配件，旅行可换路线示例或地图呈现，资料整理可换示意材料及报告组织。用户锁定原主体时保留主体，调整其他表达层。

记录该篇实际采用的条件、对象和参数，供输入、对话、结果、图片和正文共同使用。无需改变的参数不为了差异强行替换。

### 4. 重写文案、指令、成果和分镜

围绕保留的核心重新组织标题、正文、图内文字和相关话题，从新的表达方案写起。重新安排论述顺序和具体动作，避免沿原文逐句替换。删去空泛夸赞和制作口吻，保持自然的使用者表达。

涉及工具操作时，写出可读、可复制的用户指令，再准备对应的可见成果。改过的条件贯穿任务名、输入、对话、文件名、输出卡、预览及正文；只需修改与该条件有关的内容。

每页提供新信息，页数由内容及用户要求决定。保留原文的重要功能、过程与收益，不能为了缩短文案漏掉关键锚点，也不为凑页重复同一张结果。

### 5. 改造视觉并保证内容准确

图文任务用图像生成工具修改或创作主体、场景、背景、配色和构图。提示词写清原参考的用途、保留部分、替换部分及本篇准确内容；不要把 AI 创作缩成空底色。

原搭子界面可以复用。产品品牌、控件和布局有真实素材依据；其中需要改写的场景文字和结果按本篇条件同步调整。默认无需每篇重新登录运行任务，用户要求实测时再实际操作。

长中文、品牌、数字和密集图表逐字核对；必要时保真贴图或准确排字。图像编辑遵循当前工具规则，需要程序合成时使用已有适用授权；不能自行以程序重绘替代默认图像编辑工具。

同篇主体、对象和参数一致，篇内视觉协调，篇间构图有区别。保留原素材；记录实际生图提示词、素材来源、复用范围及局部修正。复用同一素材生成多个排版页时，不把这些页面记为多次独立生图调用。

### 6. 检查核心、改写范围和前后一致性

对照原稿与最终成品检查：

- 核心表达是否仍相同，关键锚点是否完整，重要条件和结论是否被误改。
- 应替换的文字和例子是否已重写；改过的城市、姓名、日期、服装、文件等是否还有旧内容残留。
- 输入、指令、对话、成果、图表和正文是否属于同一篇任务；数值、对象和建议是否相互对应。
- 文案结构和图文形式是否有实际变化，同批各篇是否有区别。
- 图片是否有乱码、遮挡、拉伸、糊小字或品牌错误；提示词与成果是否清楚可读。

逐图看原尺寸，再看手机阅读尺寸和整组预览。文字检索辅助检查，不替代看图。发现问题修最终文字或图片，不能只改提示词或补解释。

内部区分原始截图、AI 场景、示意成果和本次实测；合成内容不记录为原始截图或实际运行结果。示意数据可随示意场景调整，真实引用内容保持准确。

### 7. 交付和记录

按用户范围交付。纯文字任务给完整新稿；图文任务默认交付有序图片、标题/正文/话题、可复制用户指令、整组预览和 ZIP。图片默认3:4，用户指定的尺寸和页数优先。

保存原参考、保留/替换清单、各篇表达方案、准确内容与参数、实际生图提示词、来源和修正记录。检查文件数量、预览引用和 ZIP 完整性。原稿和旧版保留；发布或外部同步按当轮授权执行。

## 主题迁移举例

| 原文核心表达 | 可替换的表达形式 | 保留的核心 |
| --- | --- | --- |
| 搭子根据天气教你穿搭 | 衣物组合、穿搭示意、开场角度、卡片排版与配色；示意条件变动时同步改建议 | 天气指导穿衣；原文关键功能和报告内容仍完整 |
| 搭子帮你规划旅行 | 路线示例、叙述顺序、地图与行程展示；按用户范围调整地点 | 搭子规划旅行，必要条件和成果内容不遗漏 |
| 搭子帮你整理资料 | 示意文件、说明角度、报告版式和成果展示 | 搭子处理资料并给出可用的整理结果 |

总检查问题：**读者收到的核心意思是否相同，而文章和图片是否已经换了一种表达？**
